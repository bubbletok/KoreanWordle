# Korean Wordle

한글 낱말 맞추기(Wordle) Unity 모바일 게임.

초성/중성/종성 조합(모아쓰기, Blocked)과 자모 분해(풀어쓰기, Deblocked) 두 가지 모드를 지원합니다.

- **엔진:** Unity 6000.0.72f
- **플랫폼:** Android
